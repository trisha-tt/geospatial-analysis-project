## Geospatial Analysis: Analysis of Frequent Locations and Movement Patterns
### CPTS 475: Project
### Fall 2025

This project aims to analyze a dataset containing location records for 20 individuals to recognize patterns and identify frequently visited locations.

The dataset contains time-stamped location coordinates, keeping a record of a person’s location on a certain date and time. (Due to size of dataset, it is not included in the repository)

From this, we can map out a person’s daily schedule and movement patterns.
We can also estimate their home and work locations, based on the amount of time spent and what time of day they visit that location.

Lastly, this analysis can then be used to train a predictive model that can guess a person’s location based on the time and day of the week.

Heatmaps can be viewed in /code/maps/heatmap[ClientID].html

The heatmaps are generated by code/map[ClientID].py

Model can be found in code/model.py

To run DBSCAN for the dataset and view exact coordinates of top locations, run helper script `run_all.sh` which can be found in the root directory.

Usage:
Make the script executable (optional):
```bash
chmod +x run_all.sh
```

Run with the default Python (`python3`):

```bash
./run_all.sh
```
